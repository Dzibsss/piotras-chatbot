# 🌌 Gemini Ultra Chat

A complete, production-ready chatbot built with **Next.js 15**, **TypeScript**, **Tailwind CSS**, and **Google Gemini 1.5 Flash**.

## ✨ Features
- **Modern UI:** Sleek Glassmorphism interface with dark mode.
- **AI Integration:** Powered by Google's latest `gemini-1.5-flash` model.
- **Context Aware:** Remembers conversation history for natural interaction.
- **Responsive:** Mobile-first design that looks great on all devices.
- **Animations:** Smooth transitions using Tailwind CSS and Lucide icons.

## 🚀 Quick Start (Local)

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Configure API Key:**
   - Create a `.env.local` file (or rename the template).
   - Get your API Key from [Google AI Studio](https://aistudio.google.com/app/apikey).
   - Add it to the file:
     ```env
     GEMINI_API_KEY=your_actual_api_key_here
     ```

3. **Run the App:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to see your chatbot.

## 🌍 Deployment on Vercel

1. **Push to GitHub:** Create a new repository and push your code.
2. **Import to Vercel:** Go to [Vercel](https://vercel.com) and import your repo.
3. **Set Environment Variables:**
   - In the project settings, add `GEMINI_API_KEY` with your key.
4. **Deploy:** Click deploy and you're live!
